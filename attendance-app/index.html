One time Google activation instructions

1. Open the EDII Master Sheet in the authorised Google account. Choose Extensions and Apps Script.

2. Copy the complete Google Archive Script into Code.gs, save it, run prepareEDIIArchive and approve Google permissions.

3. Deploy as a Web App, executing as yourself. Allow access to Anyone for server delivery. Requests are checked against a private token and photographs are not shared publicly.

4. Open Render Environment and save EDII_GOOGLE_ARCHIVE_URL as the /exec URL and EDII_GOOGLE_ARCHIVE_TOKEN as the private token from Apps Script Project Settings.

5. On this dashboard select Test Google Connection, then Sync Previous Records until pending becomes zero. Keep the token private. The existing free database requires replacement before 23 December 2026.
